# きららキャラ人気投票ページ
## 1. 目的
ユーザーがWebサイト上で実際に投票し、それを集計できる機能の実装

## 2. ターゲット
「まんがタイムきらら」読者をはじめとした漫画・アニメファン

## 3. できること
-キャラ別投票：まずは作品を選択し、その次にその作品に出てくるキャラクターを選択という形で投票を進めていく<br>
-作品別投票：キャラ別投票からキャラクター選択を取り除いたもので、作品としての人気投票もできるようにということで作品別投票も実装した。

## 4. こだわり
-jsの徹底的活用：PHPがメインではあるが、重複投票の防止などでjsも積極的に活用している。<br>
-「まんがタイムきらら」のイメージに即した配色：「まんがタイムきらら」の作品には、日常系かつ可愛いキャラクターが登場する作品が多いため、桃色を採用している。
